# Hey Greg releases

Notarized builds of Hey Greg, a menu bar pet for the Mac. The source lives elsewhere; this repository holds only the builds.

**Download the latest:** https://github.com/superic/hey-greg-releases/releases/latest/download/HeyGreg.zip

Install: unzip, drag Hey Greg to your Applications folder, open it. It is signed and notarized, so it opens without any warnings. Updates keep your pet: same app, same journal.

Hey Greg sees that you worked, never what you worked on. It has no network entitlement and sends nothing anywhere. More at https://rareedge.com.
